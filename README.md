# TOEIC 700 · 英語練習室

以每天 90 分鐘、目標多益 700 分為情境的繁體中文練習網站。零第三方 JavaScript 依賴，可部署為靜態網站。

## 本機啟動

在此資料夾執行 `npm start`，開啟 http://127.0.0.1:4173 。也可以直接開啟 `dist/index.html`，但建議使用伺服器，讓瀏覽器保留固定來源的學習紀錄。

## 功能

- 8 組閱讀、24 題：工作郵件、公告、雙篇與三篇閱讀，附中文解析。
- 8 組聽力、24 題：預製英文 WAV 合成語音、原生播放控制、0.8／1／1.2 倍速、重播；交卷後顯示逐字稿。
- 60 個單字／詞組：主題與關鍵字篩選、瀏覽器英文發音、翻卡、四選一測驗。
- 間隔複習：記住後依序於 1／3／7／14／30 天複習；忘記則當天到期並重設階段。
- 錯題筆記：閱讀與聽力答錯自動加入；在重做題組時答對即移出。
- 今日任務、近七日學習圖表、各科正確率、學習歷史、25 分鐘專注計時。
- 瀏覽器 localStorage 保存學習狀態，支援 JSON 匯出／匯入。匯入會先提示取代紀錄。
- 手機與桌面響應式版面，使用原生按鈕與鍵盤可操作控制。

## 使用界線

所有內容為原創多益風格練習，並非 ETS 官方題庫，正確率不能換算為正式多益分數。現有題庫是可反覆使用的起始練習庫，並非完整八週不重複課程或標準化模擬考。

聽力音檔為 Microsoft Zira Desktop 英文合成語音，並非真人錄音或四國口音模擬。單字發音依裝置 Web Speech 語音支援情況而定。介面字型使用 Google Fonts，離線時會改用系統字型；本地練習內容與聽力檔無外部服務依賴。

紀錄僅存在此瀏覽器與網站來源，不含帳號、後端資料庫或跨裝置自動同步。請定期匯出備份。網站僅在可見且最近兩分鐘有操作時累積學習秒數，切換到背景不計時；專注倒數在背景暫停。

## 維護與檢查

`npm run check` 檢查 JavaScript 語法、題庫結構、音訊及互動狀態。新增題庫可編輯 `dist/data.js`，請保持既有題目 ID 穩定，以維持學習紀錄相容。

`audio-source.json` 是現有聽力逐字稿的音檔產生來源。Windows 已安裝 Microsoft Zira Desktop 時，可執行 `powershell -File generate-audio.ps1` 重建語音檔。

網站部署內容位於 `dist/`，站點身分與輸出設定位於 `.openai/hosting.json`。
