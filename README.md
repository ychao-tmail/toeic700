# TOEIC 700 · 英語練習室

以每天 90 分鐘、目標多益 700 分為情境的繁體中文練習網站。零第三方 JavaScript 依賴，可部署為靜態網站。

## 專案紀錄

- [版本紀錄](版本紀錄.md)：版本、功能範圍、發布資訊、驗證結果與目前限制。
- [修改紀錄](修改紀錄.md)：新增功能、調整、修正及各項變更涉及的檔案。

## 本機啟動

在此資料夾執行 `npm start`，開啟 http://127.0.0.1:4173 。也可以直接開啟 `dist/index.html`，但建議使用伺服器，讓瀏覽器保留固定來源的學習紀錄。

## 功能（v1.1.0）

- 題型涵蓋 Part 2 到 Part 7，共 150 題：
  - Part 2 應答問題 6 組 30 題，瀏覽器語音播放，交卷前不顯示選項文字。
  - Part 3、4 對話與獨白 8 組 24 題，預製 WAV 音檔，或切換「雙聲道語音」分辨說話者。
  - Part 5 句子填空 8 組 48 題，Part 6 段落填空 6 篇 24 題（含句子插入），每題標註文法技能。
  - Part 7 閱讀 8 組 24 題：單篇、雙篇與三篇閱讀。
- 程度診斷：A、B 兩套各 33 題，不計時，輪流使用。依正確率分為起步、基礎鞏固、進階衝刺、接近目標四組，並調整題組難度。滿兩週提醒做後測，結果顯示各 Part 的進退幅度。
- 計時模考：迷你版約 28 分鐘、33 題；加長版約 56 分鐘、66 題。各 Part 隨機交錯，時間到自動交卷。
- 錯題間隔複習：答錯隔天到期；到期答對後再隔 3 天，第二次答對才移出。提前重做答對不計入進度。
- 錯因分類：答錯時可標記字彙、文法、找不到依據、同義改寫、時間不夠、聽不清楚等原因，學習紀錄頁顯示分布與建議。
- 聽寫練習：聽力題組交卷後，可逐句播放、輸入並比對漏聽的字。
- 300 個單字／詞組，12 個主題：翻卡、四選一測驗（干擾選項避開意思重疊的字）、1／3／7／14／30 天間隔複習。
- 今日任務 4 項：10 個單字、文法、閱讀、聽力各一組。系統依診斷程度與各 Part 正確率推薦下一組。
- 學習紀錄：各 Part 正確率、文法技能正確率、錯因分布、測驗紀錄、近七日圖表、25 分鐘專注計時。
- 瀏覽器 localStorage 保存學習狀態，支援 JSON 匯出／匯入。v1.0.0 的備份可直接匯入，會自動轉換。

## 使用界線

所有內容為原創多益風格練習，並非 ETS 官方題庫，正確率與程度分組不能換算為正式多益分數。題庫目前為 150 題，尚不足以支撐八週不重複練習；模考與診斷使用同一題庫，可能抽到做過的題組。

尚未提供 Part 1（照片描述）。Part 3、4 預製音檔為 Microsoft Zira Desktop 單一合成語音；Part 2、雙聲道模式、聽寫與單字發音使用裝置的瀏覽器英文語音，音質與可用聲音數依裝置而定。只有一種英文語音的裝置會以音高區分說話者。介面字型使用 Google Fonts，離線時會改用系統字型。

紀錄僅存在此瀏覽器與網站來源，不含帳號、後端資料庫或跨裝置自動同步。請定期匯出備份。網站僅在可見且最近兩分鐘有操作時累積學習秒數，切換到背景不計時；專注倒數與模考計時在背景暫停。

## 維護與檢查

`npm run check` 檢查 JavaScript 語法、題庫結構、音訊及互動狀態。

- `dist/data.js`：v1.0.0 的 Part 3、4、7 題庫與前 60 個單字。
- `dist/data-more.js`：v1.1.0 新增的 Part 2、5、6 題庫、第 61–300 個單字與診斷 A、B 套題組成。

新增題目請保持既有題目 ID 穩定，以維持學習紀錄相容。Part 5、6 題目需有 `skill` 欄位；Part 6 文章以 `[1]`、`[2]` 標示空格。

`audio-source.json` 是現有聽力逐字稿的音檔產生來源。Windows 已安裝 Microsoft Zira Desktop 時，可執行 `powershell -File generate-audio.ps1` 重建語音檔。

網站部署內容位於 `dist/`，站點身分與輸出設定位於 `.openai/hosting.json`。
